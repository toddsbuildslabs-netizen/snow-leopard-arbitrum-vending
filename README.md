# 🐆 The Snow Leopard on Arbitrum One
*Automated On-Chain Vending Machine & Community Follower Portal*

## Overview
**The Snow Leopard** is a decentralized public-good initiative built on **Arbitrum One**, combining wildlife conservation advocacy with low-cost, high-speed automated token distribution. The protocol operates completely autonomously 24/7, providing instant token acquisition and verified community rewards while routing a portion of transactions to conservation foundations.

## Core Features
* **Automated Token Vending (`buyTokens`):** Instant native-currency-to-token purchases with built-in split logic (directing funds securely to operational maintenance and charity foundations).
* **Sybil-Resistant Claim Portal (`claimFreeTokens`):** Secure cryptographic verification (`validClaimCodes`) to reward verified community supporters and followers safely.
* **Arbitrum Layer 2 Optimized:** Engineered for maximum efficiency and minimal gas fees on Arbitrum One.
